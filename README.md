# Amin E-Commerce Management System

## 1. Project Description

Amin E-Commerce Management System is a web-based application developed for an e-commerce business. This system provides a simple and user-friendly interface to manage important business information, including products, orders, customers, and sales analytics.

The project is developed as part of the IMS566 Individual Project using HTML, CSS, JavaScript, and Bootstrap 5.

## 2. Features Included

The system includes the following features:

- **Login Page:** Allows users to access the system using their login credentials.
- **Registration Page:** Provides a registration interface for new users.
- **Dashboard:** Displays an overview of the e-commerce management system.
- **Product Management:** Displays product information and product records.
- **Order Management:** Provides an interface to view and manage customer orders.
- **Customer Management:** Displays customer information and records.
- **Analytics:** Presents business information through charts and data visualisation.
- **Responsive Design:** Provides a user-friendly interface for different screen sizes.

The project uses the following technologies:
